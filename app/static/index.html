How a short link works

One request. One lookup. One redirect.

  1. Visitor opens the link

    The browser requests the short alias.

    GET /spring-sale

  2. Alias is looked up

    The API finds the long URL in SQLite.

    SQLite · in memory

  3. Visit is counted

    Expiry is checked and the visit recorded.

    visits + 1

  4. Browser is redirected

    A real HTTP redirect to the long URL.

    307 → long URL
