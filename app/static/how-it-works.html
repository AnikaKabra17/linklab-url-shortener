The brief

Problem statement

A minimal service to redirect long URLs to short aliases.
  • POST /shorten turns a long URL into a unique short alias.
  • GET /{alias} answers with a real HTTP 307 redirect.
  • Custom aliases, expiry, visit counts and QR codes.

Architecture

A lightweight API using an in-memory SQLite database inside a single container.
  • FastAPI serves the API, these pages and every redirect.
  • SQLite runs as :memory:, with no database file.
  • One Docker image, one process, port 8000.

Request flow

Life of a short link

POSTCreate · /shorten

  1. Validate the long URLhttp or https only, a real hostname, up to 2,048 characters.
  2. Choose the aliasYour custom alias, or 7 random characters from a secure generator.
  3. Store it in SQLiteThe primary key guarantees every alias is unique.
  4. Return 201 CreatedThe short link, ready to share.

GETRedirect · /{alias}

  1. Look up the aliasA single indexed query against SQLite.
  2. Check expiryExpired links return 410 and never redirect.
  3. Count the visitIn the same transaction, so no visit is lost.
  4. Return 307 RedirectThe browser goes straight to the long URL.
